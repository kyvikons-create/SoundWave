# SoundWave

музыкальный плеер для soundcloud под айфон. начинал как веб-морда, потом обернул в нативное приложение и допилил до состояния "пользуюсь каждый день".

## что умеет

- поиск по трекам и исполнителям
- подборки по жанрам (хип-хоп, электроника, phonk, lofi и т.д.)
- очередь, перемешивание, повтор, автоплей похожих треков
- таймер сна и регулировка скорости воспроизведения
- любимые треки и история прослушиваний (хранятся на телефоне)
- играет в фоне, управление с экрана блокировки

## сборка

клонировать репозиторий и запустить сборку в github actions (вкладка actions -> run workflow), в артефактах появится SoundWave.ipa.

если есть мак с xcode — можно локально:

```
bash build.sh
```

## установка на iphone

ipa подписывается своим apple id через [sideloadly](https://sideloadly.io) или altstore. с бесплатным apple id подпись живёт 7 дней, потом просто переустановить. данные и любимые треки при этом сохраняются.

## как устроено

обычный wkwebview, внутри которого весь интерфейс (index.html, без фреймворков и сборки). запросы к api soundcloud идут через нативный мост на nsurlsession — так обходим ограничения cors браузера. ключ api подтягивается автоматически, если вдруг перестал работать — в настройках есть кнопка "найти автоматически".

минимальная версия ios — 15, тестировалось на ios 18.

неофициальный клиент для личного использования, весь контент принадлежит soundcloud и правообладателям.
