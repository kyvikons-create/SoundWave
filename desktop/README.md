# SoundWave Desktop

заготовка десктоп-версии на electron. тот же интерфейс, что в ios-приложении, только в окне на компьютере.

## запуск

нужен [node.js](https://nodejs.org). дальше из этой папки:

```
npm install
npm start
```

если electron не качается (сеть режет github), используйте зеркало:

```
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm install
npm start
```

## как устроено

- `main.js` — окно + сетевой мост: все запросы идут через главный процесс electron, где нет ограничений cors (та же схема, что в ios-версии с wkwebview)
- `preload.js` — прокидывает `__swNativeFetch` в страницу, интерфейс думает, что работает с нативным мостом
- интерфейс берётся из `../index.html` — одна кодовая база на все платформы

## что можно допилить

- глобальные хоткеи (play/pause из любой программы) — globalShortcut в main.js
- трей-иконка с управлением
- нормальные размеры окна/адаптив под широкие экраны
- автозапуск с системой
